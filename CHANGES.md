# Perubahan (pembaruan paritas TradingView)

- Perbaikan bug: dropdown (timeframe, jenis chart, indikator, layout, pengaturan, popup tanggal) terpotong header; kini `position:fixed`.
- Perbaikan bug: legend tidak ter-update saat indikator terakhir dihapus; dropdown jenis chart kini menutup setelah memilih.
- Dialog Indikator ala TradingView (pencarian, kategori, daftar aktif) dengan 49 indikator baru (src/js/03b-xind.js, 10b-indlg.js).
- Jenis chart baru: Renko, Line break, Kagi, Point & figure, Range (src/js/03c-types.js; selaras dengan sumbu waktu bar sumber).
- 15 drawing tools baru (src/js/08b-toolsx.js).
- Tombol pencarian cepat, label Alert/Replay, tab pengaturan Trading/Alerts/Events.
- Gelombang 2: 19 drawing tools lagi (Schiff/Modified Schiff, Flat top/bottom, Fib channel/arcs/spiral, Gann fan, Cypher, Cyclic lines, Sine line, Anchored VWAP, Fixed range volume profile, Triangle, Rotated rectangle, Note, Price note, Callout, Comment, Pin).
- UI/UX: layout mobile ala TradingView mobile (chart memenuhi layar, toolbar gambar di bawah, dropdown jadi bottom sheet, toolbar drawing melayang satu baris, bar bawah ringkas).
- Rasa pakai drawing: jenis kursor Cross/Dot/Arrow, magnet lemah/kuat (klik berulang pada tombol magnet), shortcut Alt+J (horizontal ray) dan Alt+Shift+R (rectangle).
- Berdasarkan pengujian langsung TradingView (login): toolbar melayang drawing kini berisi Templates, Line tool colors, Line tool text colors, Line tool width, Style, Settings, Add Alert, Lock, Remove, More (08c-selbar.js).
- Dialog pengaturan garis: tab Style (ujung kiri/kanan, Extend, Middle point, Price labels, Stats/posisi/Always show stats), tab Text (teks, ukuran, bold, italic, warna, perataan), Coordinates, Visibility, tombol Template (simpan/terapkan template per jenis tool) (06b-lineopts.js, 12-boot-settings.js).
- Gelombang 3 (08d-toolsz.js): sisa drawing tools dari daftar resmi TradingView (Drawings List): Disjoint channel, Inside pitchfork, Gann square (+fixed), Trend-based fib time, Pitchfan, Fib wedge, Highlighter, Path, Curve, Polyline, Arc, Double curve, Anchored note, Signpost, Arrow marker, Arrow mark left/right, 4 gelombang Elliott lain, Time cycles, Position forecast, Bars pattern, Ghost feed, Sector; kursor Demonstration. Path/Polyline selesai dengan double-click atau Enter. Nama tool disesuaikan dengan TradingView.
- Berdasarkan pengamatan langsung TradingView (login): menu interval (Ticks, Seconds, Minutes, Hours 1-4, Days, Ranges), jenis chart (+Volume footprint, TPO, Session volume profile; dihitung dari OHLCV, bukan data tick), dialog Create alert (Condition, Add condition, Trigger, Expiration, Message, Notifications), pengaturan chart (Title, Open market status, Last day change, Indicators titles/inputs/values/background, Scale modes, No overlapping labels, Previous day close, Day of week, Date format, 12/24 jam, Extended zoom out, Watermark, Margins), sidebar (Watchlist, Alerts, Details and News, Object tree, Data window, Screeners, Calendars), dialog Indikator (PERSONAL Favorites, BUILT-IN), label "All" pada rentang tanggal.
